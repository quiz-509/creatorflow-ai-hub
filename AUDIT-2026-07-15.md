## 1. ARCHITECTURE GLOBALE

**Séparation des responsabilités : NON — partielle et incohérente**

- Frontend : 39 pages HTML avec React via CDN, inline JS de 2000+ lignes par fichier. Pas de build, pas de tree-shaking, pas de composants réutilisables.
- Edge Functions : monolithes de 600 à 1163 lignes. `marketing-heartbeat/index.ts` fait tout : infrastructure email, décision IA, gestion de portefeuille, métriques RH, synthèse d'expérience.

**Dépendances incohérentes — problèmes confirmés :**

| Problème | Impact |
|----------|--------|
| `stripeKey` référencé dans `handleCheck()` mais hors scope | Bug runtime silencieux — Stripe ne fonctionne pas |
| `agent_heartbeats` status constraint = 'ok'/'alert_sent'/'error' mais code insère 'running'/'completed' | **Toutes les insertions heartbeat échouent** |
| `employee_handoffs` table créée, jamais utilisée | Dead code DB |
| `company_memory` initialisée, jamais lue ni écrite | Mémoire entreprise inexistante |

**Risques majeurs :**
- Bug heartbeat status = tous les logs agents sont cassés depuis le déploiement
- Zéro test = chaque déploiement est un saut dans le vide
- 0 monitoring des Edge Functions — un heartbeat qui plante est invisible

## 6. CODE

**Bug critique #1 — `stripeKey` hors scope dans marketing-heartbeat**
`handleCheck()` référence `stripeKey` déclaré dans `Deno.serve()`. En Deno, la variable n'est pas accessible. `stripeKey = undefined` ou ReferenceError. Stripe ne fonctionne pas pour Aria.

**Bug critique #2 — `agent_heartbeats.status` constraint cassée**
Constraint : `CHECK (status IN ('ok','alert_sent','error'))`
Les heartbeats insèrent `'running'` et `'completed'` — violation silencieuse. Tous les logs heartbeat sont vides en production.

**Code mort à supprimer :**
- `supabase/functions/ai-agent/index.ts` — legacy confirmé
- `supabase/functions/blog-monitor/index.ts` — legacy confirmé
- `supabase/functions/marketing-director/index.ts` — legacy, remplacé

**Duplication critique :**
`callClaude()`, `loadProfile()`, `loadExperience()`, `synthesizeExperience()`, `updateMetrics()` — copiés-collés dans 4 fichiers. Un bug dans l'un = bug dans les 3 autres.

**Sécurité :**
- Email admin hardcodé dans HTML — CRITIQUE
- RLS à valider sur tables core
- CORS `*` sur toutes les Edge Functions — à restreindre sur les fonctions admin

## 7. PARCOURS CLIENT

**Flux réel :**
```
Client → Brief → CEO assigne manuellement → Aria pickup → Délégation → Livraison → Feedback → Révision
```

**Frictions identifiées :**
1. **Assignation manuelle** : si le CEO est absent, les briefs s'accumulent. Aria devrait auto-pickup les briefs non assignés.
2. **Délai 24h minimum** entre chaque action (heartbeat quotidien).
3. **Erreurs silencieuses** : si Resend ou Anthropic key vide, le code catch tout, le client ne reçoit rien, personne n'est notifié.
4. **Pas de timeline visible** pour le client — il ne sait pas où en est son projet.
5. **Pas de notification temps réel** quand Aria prend une décision.
