## GUIDE D'UTILISATION DES PROMPTS

### Pour Midjourney (v6.1)

```
--ar 1:1 --v 6.1 --style raw --q 2
```
Pour les variantes buste : remplacer `--ar 1:1` par `--ar 16:9`.

### Pour Leonardo AI

Utiliser le modèle **PhotoReal v2** ou **Flux Dev**.
- Guidance scale : 7-8
- Coller le prompt dans "Positive Prompt"
- Negative prompt : `cartoon, anime, illustration, painting, CGI, 3D render, plastic skin, oversmoothed, AI-looking, artificial, stock photo pose, generic`
- Steps : 40-50

Modèle recommandé : `flux-dev` ou `flux-schnell`
- CFG Scale : 3.5 (Flux est moins sensible que SD)
- Steps : 28-35
- Le prompt tel quel fonctionne très bien avec Flux pour les portraits réalistes

### Pour Ideogram v2

Utiliser le mode **Photo Realistic**.
Ajouter en fin de prompt : `photorealistic, professional photography, 8K, ultra-detailed`
